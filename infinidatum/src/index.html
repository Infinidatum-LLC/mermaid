1. Draw a themed, animated diagram

One script tag, then <infd-diagram> anywhere. The diagram builds in the order it reads when it scrolls into view: flowcharts, state and class diagrams by distance from the start, sequence diagrams message by message. Next step and the arrow keys walk it one stage at a time. Hover a box to light it and its neighbors. 

<script type="module" src="https:///v/{{VERSION}}/diagram.js"></script>

<infd-diagram caption="A person checks every draft before a member sees it."
              alt="Staff ask, the AI drafts, a person reviews, then it is sent or fixed.">
flowchart LR
  A[Staff ask]:::person --> B[AI drafts]:::ai --> C{Reviewed?}
  C -->|Yes| D[Send]:::done
  C -->|No| E[Fix or discard]:::risk
</infd-diagram>
flowchart LR A[Staff ask]:::person --> B[AI drafts]:::ai --> C{Reviewed?} C -->|Yes| D[Send]:::done C -->|No| E[Fix or discard]:::risk

2. Options

Attribute Values
caption One sentence above the diagram.
alt The flow in words, for screen readers. The SVG itself is hidden from them.
animate auto (default) or none. Reduced-motion users always get none.
speed Animation speed, 0.25 to 4. Default 1.
controls none hides Back, Next step and Replay.
theme light (default), dark, or auto to follow the reader. --infd-* variables still win.
flow dots sends dots along the arrows once the diagram is complete.
highlight hover (default) lights a box and its neighbors; none turns it off.
focus Node ids, comma-separated, to keep lit while the rest dims.
tools Any of zoom fullscreen export, or all. Zoom with the buttons, or Ctrl/⌘ and the wheel; drag to pan. Export saves SVG or PNG.
src URL of a .mmd file to draw instead of the element's text.
fit auto (default) draws a flowchart both ways and keeps the one that fits the column. authored keeps your direction.

Box classes: :::person :::ai :::check :::risk :::done. Their colors come from CSS custom properties you set on any ancestor: --infd-card, --infd-panel, --infd-ink, --infd-ink-soft, --infd-rule, --infd-accent, --infd-ai, --infd-ai-bg, --infd-good, --infd-good-bg, --infd-risk, --infd-risk-bg, --infd-font. Any CSS color works. Other diagram types (pie, gantt, mindmap) draw too, without the step animation.

Set element.code = "..." to redraw from script. Methods: play(), next(), prev(), goTo(n), toSvg(), toPng(), download("svg" | "png"). Events: infd-drawn, infd-step, infd-node-click, infd-error. Reduced-motion readers get the finished diagram, with no dots.

3. Embed it anywhere

An iframe, for a CMS, LMS or any page that cannot add a script. Settings go in the URL fragment, which never reaches the server. Colors are passed by name (accent=%23ff8800), since an iframe cannot inherit the page's variables. /api/oembed?url=… answers oEmbed for these links. 

<iframe src="https:///v/{{VERSION}}/embed.html#code=flowchart%20LR%0A%20A--%3EB&caption=Hello&theme=dark"
        style="border:0;width:100%;height:320px" loading="lazy"></iframe>

The client SDK, one import for every use: draw in the page, embed an auto-sized iframe, check syntax, or get an image from the server. 

import * as infd from "https:///v/{{VERSION}}/client.js";

await infd.render("#lesson", code, { caption: "How it works", theme: "auto", flow: "dots" });
infd.embed("#sidebar", code, { caption: "Isolated in an iframe" });   // resizes itself
await infd.parse({ intro: code1, recap: code2 });                     // CI checks
const svg = await infd.renderSvg(code, { theme: "dark" });            // server-drawn
const src = infd.imageUrl(code, { format: "png" });                   // for <img>, email

4. Images from the server

/api/render draws with this exact build and theme, in headless Chrome, for email, PDFs and Markdown. GET answers are cached by the CDN. Options: format (svg, png), theme, scale (PNG, 1 to 4), labels, and colors by name as hex. A syntax error answers 400 with the line. 

<img alt="Ask, then draft"
     src="https:///api/render?format=png&code=flowchart%20LR%0A%20A%5BAsk%5D--%3EB%5BDraft%5D">

curl -s https:///api/render -H 'content-type: application/json' \
  -d '{"code": "flowchart LR\n A --> B", "format": "png", "theme": "dark"}' -o diagram.png

5. Use plain Mermaid

import mermaid from "https:///v/{{VERSION}}/mermaid.esm.min.mjs";
// or the classic build: <script src="https:///v/{{VERSION}}/mermaid.min.js"></script>

/v/{{VERSION}}/ never changes and is cached for a year. /latest/ follows the fork and is cached for five minutes. Pin a version in production.

6. Check diagrams in CI

POST /api/parse checks syntax with this exact build. A syntax error comes back as ok: false with the message and line. 

curl -s https:///api/parse \
  -H 'content-type: application/json' \
  -d '{"diagrams": {"lesson-1": "flowchart LR\n A --> B", "lesson-2": "flowchart LR\n A[x --> B"}}'
