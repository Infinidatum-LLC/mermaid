1. Draw a themed, animated flow

One script tag, then <infd-diagram> anywhere. The flow builds in order when it scrolls into view. Next step walks it one stage at a time. 

<script type="module" src="https:///v/{{VERSION}}/diagram.js"></script>

<infd-diagram caption="A person checks every draft before a member sees it."
              alt="Staff ask, the AI drafts, a person reviews, then it is sent or fixed.">
flowchart LR
  A[Staff ask]:::person --> B[AI drafts]:::ai --> C{Reviewed?}
  C -->|Yes| D[Send]:::done
  C -->|No| E[Fix or discard]:::risk
</infd-diagram>
flowchart LR A[Staff ask]:::person --> B[AI drafts]:::ai --> C{Reviewed?} C -->|Yes| D[Send]:::done C -->|No| E[Fix or discard]:::risk

2. Options

Attribute Values
caption One sentence above the diagram.
alt The flow in words, for screen readers. The SVG itself is hidden from them.
animate auto (default) or none. Reduced-motion users always get none.
controls none hides Next step and Replay.
fit auto (default) draws a flowchart both ways and keeps the one that fits the column. authored keeps your direction.

Box classes: :::person :::ai :::check :::risk :::done. Their colors come from CSS custom properties you set on any ancestor: --infd-card, --infd-panel, --infd-ink, --infd-ink-soft, --infd-rule, --infd-accent, --infd-ai, --infd-ai-bg, --infd-good, --infd-good-bg, --infd-risk, --infd-risk-bg, --infd-font. Any CSS color works. Other diagram types (sequence, class, gantt) draw too, without the step animation.

Set element.code = "..." to redraw from script. The element fires infd-drawn and infd-error.

3. Use plain Mermaid

import mermaid from "https:///v/{{VERSION}}/mermaid.esm.min.mjs";
// or the classic build: <script src="https:///v/{{VERSION}}/mermaid.min.js"></script>

/v/{{VERSION}}/ never changes and is cached for a year. /latest/ follows the fork and is cached for five minutes. Pin a version in production.

4. Check diagrams in CI

POST /api/parse checks syntax with this exact build. A syntax error comes back as ok: false with the message and line. 

curl -s https:///api/parse \
  -H 'content-type: application/json' \
  -d '{"diagrams": {"lesson-1": "flowchart LR\n A --> B", "lesson-2": "flowchart LR\n A[x --> B"}}'
